The local mirror does not alter audio bytes. URL rewriting, catalogue generation, additional Dirt registration and the `xxc_` names for original studio drums are application integration changes. Each source revision is pinned in `config/sample-banks/sources.json`; exact fetched locations and SHA-256 values are in `audio-lock.json`. Browser delivery uses a controlled, content-addressed endpoint outside the user upload system.

Creative Commons legal texts are retained from the SPDX license-list-data text copies; authoritative license URLs are linked above. Upstream notices are copied without changes. This sample inventory was checked on 2026-10-02.
